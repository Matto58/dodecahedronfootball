# Dodecahedron Football
It's football played with a dodecahedron.
## Controls
In the format of keyboard (Xbox controller) - action:
* W/S (left stick up/down) - forward, backward
* A/D (left stick left/right) - look left/right
* Shift (X or left stick press) - sprint (uses stamina)
* Space (A) - jump
* Esc (Menu) - pause (unimplemented)
